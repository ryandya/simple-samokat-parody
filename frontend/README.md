# Client Nav

Simple mobile store built with Expo, React Native, React Navigation, TanStack Query and Redux Toolkit.

## Commands

```bash
npm install
npm start
npm run typecheck
expo start
```

Platform shortcuts: `npm run android`, `npm run ios`, and `npm run web`.

## Environment

Create `.env` in the project root and set the backend origin:

```dotenv
SERVER_URL=https://example.com
```
